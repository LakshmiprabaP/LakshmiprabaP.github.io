# Lakshmi Praba P - Portfolio

Static portfolio prepared for GitHub Pages. No build step or dependencies are required.

## Publish

1. Create a public GitHub repository named `LakshmiprabaP.github.io`.
2. Upload the contents of this folder to the repository root (not a nested folder).
3. Commit the files. GitHub Pages should publish the site at `https://LakshmiprabaP.github.io`.
4. If needed, open **Settings > Pages** and select **Deploy from a branch**, `main`, `/ (root)`.

## Files

- `index.html` - portfolio content and SEO metadata
- `style.css` - responsive visual design
- `script.js` - navigation and subtle reveal animation
- `Lakshmi-Praba-P-Resume.pdf` - downloadable resume
- `.nojekyll` - tells GitHub Pages to serve the static files directly
